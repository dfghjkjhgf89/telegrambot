# FinanceBot

FinanceBot is a Telegram bot for managing shared expenses in groups. It helps automate the calculation of debts, generate reports, and manage financial operations through a chat interface and a complementary WebApp.

This project is being developed based on the technical specification provided by Arthur Utenkov.

## Project Structure
- `/bot`: Contains the Aiogram-based Telegram bot code.
- `/api`: Contains the FastAPI backend for the WebApp and other API integrations.
- `/webapp`: Will contain the React-based frontend application.
- `/db`: Holds database schema scripts and potentially migration files.
- `/tests`: Contains unit and integration tests.

## Tech Stack
- **Backend & Bot**: Python 3.10+, Aiogram, FastAPI
- **Frontend**: React (to be developed)
- **Database**: PostgreSQL 14
